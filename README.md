# DCHANNEL / Wickhive fan-made website

- `index.html`을 브라우저에서 열면 바로 실행됩니다.
- 기본 게시판 5개(잡담, 임무, 뒷 정보, 아카데미, 괴이), 각 게시판별 샘플 게시글 5개와 댓글 포함
- 글쓰기, 댓글/답글, 검색, 정렬(최신순/댓글순/추천순), 추천/비추천, 상단 고정/공지, 신고/숨김
- 제작자 관리 모드, 게시판 추가, JSON 백업 내보내기/불러오기
- localStorage 자동 저장

중요: 팬메이드 정적 프로토타입입니다. 데이터는 현재 브라우저에만 저장되고 다른 기기와 공유되지 않습니다. 제작자 관리 모드는 실제 인증이나 보안 기능이 아닙니다. 실제 다중 사용자 서비스에는 서버, 데이터베이스, 인증이 필요합니다.
